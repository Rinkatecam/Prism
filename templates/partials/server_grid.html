{# Tag ink solver — Jinja port of tools/tag_ink.py's tag_pill_tokens(). An admin-chosen tag colour has no readability guarantee (the default grey measured 4.37:1 on bg-card in light, 3.47:1 in dark — both under AA), and the fix cannot just replace the colour with a fixed neutral: that discards the only thing distinguishing one tag from another at a glance. So the hue is kept and the ink is nudged toward black/white in 6% steps, capped at 24, until the composite clears 4.5:1 in EACH theme — matching the JS solver in servers.html and the identical macro pair in server_card.html byte-for-byte, and verified to agree with tools/tag_ink.py by tests/test_tag_ink.py. Two custom properties (one per theme) are emitted rather than one, because baking a single theme's ink into an inline style is exactly the bug this replaced elsewhere: it goes stale the instant someone flips the theme without a reload. A static `dark:` class picks the right one live — see the button's class list below. #} {%- macro _tag_ink_solve(r, g, b, tint_alpha, bgr, bgg, bgb, target) -%} {%- set comp_r = r * tint_alpha + bgr * (1 -
