{# Shared prose CSS for compliance_sop.html and compliance_doc.html. Kept in a partial so both pages render identically — drift between the two stylesheets was an explicit pain-point pre-Wave-B. Design notes: * ``.doc-prose`` is the article wrapper. All selectors below are scoped under it (rather than per-page #sop-body / #doc-body) so the partial can drop into any future doc page without rewiring. * Pygments classes (``.k``, ``.s2`` etc.) are styled minimally — enough for keywords / strings / comments to read distinctly, but no rainbow. Reads well in both light and dark mode. * Tables get zebra-striping + a sticky header that's useful for the 30-row traceability matrix and the 23-row CSV-doc index. * Callouts (``.callout-note``, ``-tip``, ``-warning``, …) pick up colour-coded left-borders and a tinted background so an operator skimming a SOP sees "Warning:" before they read it. #}
