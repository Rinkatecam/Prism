Workflow Builder Guide

1 Start with a Trigger

Every workflow begins with one Trigger block (the teal section in the palette). Drag one onto the canvas first:

  • Manual — runs only when you click Run.
  • Schedule — daily / weekly / monthly at a set time.
  • Event — fires when a condition flips false → true on a server (service stopped, process missing, port closed, CPU/RAM/disk over threshold).

Event triggers are edge-triggered — they fire on the transition, not every poll. After choosing an event type the form re-shapes to show only the fields that event needs.

2 Adding & Connecting Blocks

Drag blocks from the left palette. Connect them by dragging from an output port (right side) to an input port (left side).

Check blocks have two outputs and the connection line is colored to match the path it leaves from: green = success / true, red = failure / false. You can see at a glance which branch a wire belongs to.

3 Configuring Blocks

Left-click a block to open the Properties Panel on the right. Set server, service/process/port name, script, etc.

Browse buttons next to service / process / port fields list what's actually running on the chosen server right now — no more typing names from memory.

In notification text fields (email body, webhook message, log message) the {% raw %}{{x}}{% endraw %} picker inserts variables: {% raw %}{{step.<id>.output}}{% endraw %}, {% raw %}{{step.<id>.success}}{% endraw %}, {% raw %}{{step.<id>.error}}{% endraw %}, and {% raw %}{{workflow.name}}{% endraw %}. They resolve at execution time from upstream blocks.

4 Canvas Navigation & Selection

Pan: click + drag on empty canvas
Zoom: mouse wheel, or +/- buttons (bottom right)
Move block: click + drag the block
Select one: left-click
Multi-select: Ctrl+click each block to toggle, or Ctrl+drag on empty canvas to draw a marquee — any block the box touches joins the selection.

With a selection: arrow keys nudge by 10 px (Shift = 50 px), Delete removes them all, and dragging any one block drags the whole group together.

5 Right-Click Context Menu

Right-click on a block: Enable / Disable, Clone, or Delete — without opening the properties panel.

Right-click on a connection line: Enable / Disable or Delete that single wire.

Disabled blocks and wires are dimmed and skipped at run time. Useful for parking part of a workflow temporarily without rewiring it.

With multiple blocks selected, the context menu acts on the whole group (Delete all, Disable all, Clone all).

6 Block Types

Triggers — Manual / Schedule / Event. Required as the first block. 0 inputs, 1 output.
Checks — Test something (service, process, port, URL, threshold). Two outputs: success (green) + fail (red).
Actions — Do something (restart service, kill process, run script, reboot, etc.). Sandboxed PowerShell.
Flow Control — Wait, Retry, AND / OR gates for branching.
Notifications — Email, webhook, log event. Use the variable picker to embed upstream data.

7 Tags & Categories

Categories color-code workflows and filter the list. Click + next to the category bar to add one; hover any custom category and click the × to delete it. The built-in All category cannot be removed.

8 Example: Service Recovery
